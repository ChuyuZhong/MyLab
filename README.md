# MyLab · 个人科研工作台

GitHub Pages: https://chuyuzhong.github.io/MyLab/

一个以个人待办为首页的科研工作台。React + TypeScript + Vite，静态部署，不需要把私人数据放进 GitHub。

## 已实现

- 待办新增、编辑、完成、删除、优先级、项目、备注、中文快速添加。
- 单次 / 每天 / 工作日 / 每周指定几天 / 每月重复；完成后生成下一次，保留完成记录。独立计划日期、DDL 和提醒时间。
- 月历、日程与任务联合展示；导入 ICS（含重复、排除日期、时区定义），导出待办到系统日历。
- X 账号订阅与公众号链接导读两个独立页面；阅读归档、AI 辅助与周报衔接。
- GPU 节点与插槽真实只读查询；个人申请草稿、使用记录和文本导出。没有替代原系统提交申请或释放资源。
- 全站助手，个人兼容 Chat Completions 的接口，DeepSeek 默认配置，简洁中文翻译、限定上下文、取消生成。
- [写周报](https://chuyuzhong.github.io/MyLab/#/weekly)：选择已读公众号论文、本周实际完成的 DDL，补充工作、计划和 idea；按个人写作 Skill 生成、编辑、预览并下载 Markdown，草稿按周保存。
- 本机持久化、备份合并导入、深色模式、移动端布局、键盘快捷键（Ctrl K 搜索、Ctrl / 助手）。
- 配置文件导出与一键导入：包括个人 API Key、配对码、接口地址、来源配色及偏好；版本化校验，保留原有任务和周报。详见 [配置迁移与兼容约定](docs/CONFIGURATION.md)。

## 启动

需要 Node.js 24。

```sh
npm ci
npm run dev
```

浏览器打开终端显示的地址。生产构建：`npm run build`；逻辑验证：`npm test`。

## 真实数据与已知边界

### 公众号导读

粘贴微信文章链接，配对本机服务后加载正文及原站图片。读取使用微信移动端 User-Agent；遇到微信验证时请打开原文或手动粘贴正文，不自动重试。视频、交互内容及受限图片需查看原文。

没有公众号订阅、RSS 配置或定时采集。已载入文章保存在本机，可标为已读、调用共享 AI 辅助阅读、加入周报并导出数据备份。旧文章与周报引用保留。更新后请重启本机服务（npm run bridge）并重新配对。

### X / Tibo

预设 @thsottiaux，按用户名使用 https://fxtwitter.com/{handle}/feed.xml。无需 X Token。进入 X 页面检查更新，默认可见时每 15 分钟检查；离开页面或关闭浏览器不继续后台运行。第三方服务的收录时间可能延迟。

每个账号保留最新 20 条，收藏和周报引用的旧帖例外。显示完整正文及精确到分钟的本地时间；遇到省略号时调用 FxTwitter 状态接口补充主帖和引用帖，失败会标为节选。翻译只使用“翻译为中文。”提示词，不要求标题。

### 实验室 GPU

支持 Determined 的 `/api/v1/auth/login`、`/api/v1/agents`、`/api/v1/resource-pools` 和 `/api/v1/master`。账号、密码、系统地址由用户在本机填写，不包含在仓库。GPU 状态不随网站公开部署。

```sh
npm run bridge
```

1. 在网站“设置与数据”填写连接服务地址（默认 `http://127.0.0.1:4318`）和终端显示的配对码。
2. 在“GPU 资源 → 连接 / 登录”填写系统根地址、账号和密码。
3. 登录成功后读取节点状态。本机需要能访问实验室网络或 VPN。

连接服务仅监听 127.0.0.1，校验 Host、允许来源和随机配对码。会话、密码、X Token 不写入文件。关闭连接服务后会话失效；刷新网页后需要重新填写配对码（配对码不会写入浏览器存储）。如果浏览器询问本地网络访问，应由用户允许。部分浏览器可能不支持从 HTTPS 页面访问本机服务，可在本机开发地址运行完整界面。

默认允许生产站点和本机开发地址。自定义域名可通过 `MYLAB_ALLOWED_ORIGINS` 环境变量追加。RSS 代理默认只读 HTTPS 公网地址，并拒绝私有地址及相关重定向；可通过 `MYLAB_LOCAL_FEED_ORIGINS` 明确允许本机采集服务的订阅路径，本机订阅不跟随重定向。微信正文接口只接受微信公开文章路径，并校验每次重定向。

GPU 卡片可打开详情侧栏；页面可见时默认每 30 秒刷新。闲置卡可一键填写带节点、插槽和资源池的申请草稿。飞书文档需要登录，正式提交方式尚待确认，请通过原系统申请。

资源状态是调度分配状态，不是实时利用率；当前接口没有提供显存占用。个人草稿和“使用中/已结束”都是手动记录，不代表原系统真实操作。请通过“原管理系统”执行申请或释放资源。

### 模型接口

在设置中填写 Base URL、模型名和个人 API Key；可以先点击“测试模型连接”。默认 DeepSeek，模型名可按服务实际支持情况修改。调用直接从浏览器发送到所填接口，因此该接口必须支持跨域。密钥仅保留在当前页面内存，不写入仓库、localStorage 或普通数据备份；用户主动点击“导出配置（含密钥）”时，会包含在本机下载的明文 JSON 中，刷新后可一键导入恢复。

助手仅在用户发送时请求模型，发送前可勾选当前文章或今天待办作为上下文；文章页的“AI 阅读并加入周报”和周报生成按钮也会使用同一接口。助手没有执行 GPU 写操作或自主修改任务的工具。未填写密钥时显示本地使用指导，不伪造模型结果。

### 个人科研周报

在公众号文章阅读页点击“加入本周周报”，或者在“写周报”中选择已读、收藏或其他文章。可补充论文原题、出版信息和个人阅读笔记。完成事项按所选周的实际完成日期筛选，默认只列带 DDL 的任务，可另外勾选普通已完成待办。

“本地整理”把笔记和事项排成周报；“按我的写法生成”与助手共用模型接口，按 Skill 撰写论文评述、整理其他栏目。生成结果可直接编辑，下载为 `.md`。只有链接的文章不会被编成已读论文。详见 [周报使用与写法](docs/WEEKLY_REPORTS.md)。

可复用规则：[SKILL.md](public/skills/chuyu-weekly-report/SKILL.md)。发布版本可在页面“我的写作 Skill”中阅读和下载。仓库只保存提炼后的写作规则，原始个人周报没有上传。

### 日历、提醒与存储

- ICS 导入范围：过去 31 天至未来 366 天，重复展开上限 5000 项。同名日历重新导入时更新对应日程；不提供账号实时双向同步。
- 页面运行时每 30 秒检查提醒；浏览器后台节流、休眠或关闭页面可能延迟。重新打开会提示错过的提醒。重要 DDL 请导出至系统日历。
- localStorage 按浏览器和网站来源隔离；开发站与线上站数据互不共享。清理浏览器数据会删除记录，建议定期备份。
- 普通备份去除连接服务地址配置中的私人实验室地址、订阅接口地址、全部密钥；正文/备注/原文链接仍是个人数据。原始存储导出用于故障恢复，包含本机配置，勿公开上传。

## 发布

`.github/workflows/pages.yml` 在 main 提交、手动触发及排程时构建并部署。仓库 Settings → Pages 的构建来源应为 GitHub Actions。所有页面采用 hash 路由，支持 GitHub Pages 子目录以及直接刷新。

`.local/`、`.env*`、`node_modules/`、`dist/` 被 Git 忽略。部署只包含静态 `dist/`，本机连接服务不会部署到 Pages。请勿把 API Key 写进 `VITE_*` 环境变量，因为它们会被编译进网页。

## 验证范围

核心逻辑测试覆盖中文时间识别、重复任务、月底跨月、重复结束日期、提醒顺延、DDL 独立性、备份校验、日历往返和重复排除日期。页面还提供可选 WebMCP 的任务读取、新建和完成操作，浏览器不支持时普通交互保持可用。
